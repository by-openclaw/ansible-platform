# ADR compliance audit — traefik (2026-10-03)

Method: roles/contract_audit (PASS=10 FAIL=0 SKIP=23) + manual walk on the live guest, Authentik, Prometheus/Loki.

**Service:** `traefik` (`roles/traefik`, `playbooks/traefik.yml`) on `lxc-traefik-01` — the platform's single edge: Traefik `v3.7.11` on the host network (`:80` → `:443` redirect, `:443` TLS 1.2+ with the Let's Encrypt wildcard), 35 dynamic route files rendered by the services, HSTS on every response, the CrowdSec bouncer plugin (`v1.7.1`, vendored) in-line, the dashboard behind the admin allow-list + Authentik forwardAuth.
**Verdicts:** **PASS** · **GAP** · **N/A** · **NOT VERIFIED**; gaps are **FIX** (this PR) · **PLATFORM** · **PROPOSE** · **OWNER**. Host-level rows identical to the previous audits carry the same verdict.

## Summary — gaps ranked

| # | Checks | Finding | Where it is fixed |
|---|---|---|---|
| 1 | INF-33, INF-39 | **No metrics from the edge**: Traefik's Prometheus exporter is not enabled, so request rates, status codes and per-router latency of every service are invisible; only node/cadvisor and the blackbox probes exist. | **FIX** — entry point `metrics :8082` (host firewall: the monitoring host only), `metrics.prometheus` with entry-point/router/service labels, catalog `metrics_port: 8082` → job `traefik` |
| 2 | SEC-21, GIT-05 | Pin `v3.7.11` while `v3.7.13` is current (two patch releases). | **FIX** — `v3.7.13` (one container recreate: a few seconds on every route, announced) |
| 3 | SEC-28 (headers) | Every HTTPS response carries HSTS but no `X-Content-Type-Options` and no `Referrer-Policy`. | **FIX** — `contentTypeNosniff`, `referrerPolicy: strict-origin-when-cross-origin` on the entry-point middleware (frame options stay per application: draw.io is embedded) |
| 4 | IDN-17, SVC-37 | No `docs/services/traefik.md`. | **FIX** — this PR |
| 5 | SEC-15 | The container runs as root: it binds `:80`/`:443` on the **host network** (dual-stack without Docker's IPv6 NAT), and a non-root user cannot hold `CAP_NET_BIND_SERVICE` there. | **PROPOSE** — register OH-16 (#724); the alternative (bridge network + `ip_unprivileged_port_start`) trades the IPv6 path (nested-LXC ip6tables) |
| 6 | SEC-22 / NAM-01 / INF-35 | Writable rootfs; NetBox empty; no alert rule names the edge (5xx rate, certificate expiry come with gap 1's job). | **PLATFORM** |
