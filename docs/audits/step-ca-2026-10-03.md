# ADR compliance audit — step-ca (2026-10-03)

Method: roles/contract_audit (PASS=11 FAIL=0 SKIP=22) + manual walk on the live guest, Prometheus/Loki.

**Service:** `step-ca` (`roles/step_ca`, `playbooks/step-ca.yml`) on `lxc-stepca-01` — Smallstep CA `0.28.4` as the unprivileged `step` user, `ca.<domain>` (route internal-only, Traefik verifies the CA with the internal root), provisioners `acme` + JWK `admin@<domain>`, TLS 1.2–1.3 with two AEAD suites, badger database, root distributed to every host.
**Verdicts:** **PASS** · **GAP** · **N/A** · **NOT VERIFIED**; gaps are **FIX** (this PR) · **PLATFORM** · **PROPOSE** · **OWNER**. Host-level rows identical to the previous audits carry the same verdict.

## Summary — gaps ranked

| # | Checks | Finding | Where it is fixed |
|---|---|---|---|
| 1 | SEC-34, SEC-06 class | **The root CA key is online**: `root_ca_key` sits in the CA's state volume next to the intermediate key and the password that decrypts both — a compromise of the guest is a compromise of the root. Best practice (and the ADR's custody rule for root material) keeps the root key offline; the intermediate signs. | **OWNER** — move `root_ca_key` to offline custody (it is only needed to sign a new intermediate); the volume keeps the intermediate |
| 2 | SEC-01 | The key password copied into the state volume by the image's first-boot init is **world-readable** (`secrets/password` 0644; the keys are 0600). | **FIX** — 0600 to the CA user, asserted on every run |
| 3 | SEC-21, GIT-05 | Pin `0.28.4` while `0.30.2` is current (two minor lines). | **FIX** — `0.30.2` (one container recreate ≈ 10 s; the role's fingerprint escrow proves the root is unchanged) |
| 4 | IDN-17, SVC-37 | No `docs/services/step-ca.md`. | **FIX** — this PR |
| 5 | INF-33 | No CA metrics (`metricsAddress` not configured: issuance counts, errors). | **PLATFORM** — monitoring pass (config key + scrape) |
| 6 | SEC-27 (coverage) | The native appliances still serve self-signed certificates (PVE, PBS) although this CA exists — its ACME provisioner is the designated source for internal names. | **PLATFORM** — the native-service certificate pass (proxmox gap 8, pbs) |
| 7 | SEC-22 / NAM-01 / INF-35 | Writable rootfs; NetBox empty; no alert rule names the CA. | **PLATFORM** |
