BY-SYSTEMS — Platform Demo

The same files are published twice, on purpose, to prove both delivery paths:

  1. This page runs in the k3s application platform: a container built by CI, pulled from the platform registry, served by a pod on vm-k3s-01, published through the platform reverse proxy with TLS and single sign-on in front.
  2. The same public/ directory is also published as a GitLab Pages site by the last stage of the pipeline.

Every step is declared in the repository: no image, route, certificate or credential is set by hand. The pipeline scans the code, builds the image, and deploys with a token that is valid in this application's namespace only.
